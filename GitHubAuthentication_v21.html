🔑 Token Needs More Permissions

GitHub only lets you create or edit tokens on github.com itself — no app can do that step for you. This does the rest for you:

  1. Click Open GitHub below — it opens a token page with the right scopes already checked.
  2. Scroll down and click Generate token on GitHub, then copy it.
  3. Come back here and click Paste New Token to drop it straight into Settings.

If you're using a fine-grained token instead, GitHub can't prefill its permissions via link — set "Administration: Read & write" manually on the token's edit page.
