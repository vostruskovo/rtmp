Getting started

Schema is an offline entity–relationship modeler. Nothing leaves this browser tab.
  • Entity — drop a new table onto the canvas, then click it to edit.
  • Relate — click a source entity, then a target entity, to draw a relationship. Click the cardinality labels on the line to change them.
  • Drag entity headers to move them. Scroll to zoom, drag empty canvas to pan.
  • Save JSON / Open to persist a model as a file on disk.
  • SQL DDL generates CREATE TABLE statements from the current model.
